# Privacy Policy - TV Time Quick Tracker

Last updated: February 11, 2026

TV Time Quick Tracker is a Chrome extension that lets users view and manage their TV Time account data from the browser popup.

## Data We Process

The extension processes:

- TV Time account credentials entered by the user at login.
- Authentication tokens returned by TV Time APIs.
- TV Time account content needed to provide features:
  watched episodes, upcoming episodes, followed shows, show metadata, and search results.

## Where Data Is Stored

- Authentication data is stored locally in Chrome extension storage (`chrome.storage.local`) on the user's device.
- The extension does not run its own backend server and does not copy user data to any separate database controlled by the extension publisher.

## Network Requests

The extension sends requests only to the minimum required third-party services needed for core functionality, such as authentication, show/episode data retrieval, and artwork display.

## Data Sharing

- No personal data is sold.
- No advertising SDKs are included.
- No analytics SDKs are included.

## Data Retention

- Local authentication data remains until one of the following happens:
1. User logs out.
2. Token expires and is cleared.
3. User removes extension data.
4. User uninstalls the extension.

## User Controls

Users can:

- Log out at any time from the popup UI.
- Remove local extension data from Chrome extension settings.
- Uninstall the extension.

## Security

- HTTPS is used for all network communication.
- Sensitive data is not intentionally logged in production mode.
